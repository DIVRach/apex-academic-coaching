# Apex Academic Coaching

A responsive one-page website for a tutoring and test-prep service.

**Live site:** https://divrach.github.io/apex-academic-coaching/

## Built with

- Semantic HTML5 and ARIA landmarks
- CSS custom properties, Flexbox, and Grid (mobile first)
- Vanilla JavaScript form validation
- SEO: meta tags, Open Graph, JSON-LD

## Features

- Fully keyboard accessible, with a skip link and visible focus styles
- Responsive from phone to desktop
- Lighthouse scores of 100 for Accessibility, SEO, and Best Practices
